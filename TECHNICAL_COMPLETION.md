- PostgreSQL migration and production-data compatibility against the actual database.
- Paystack test/live transactions, webhook delivery, refunds, transfers and settlement.
- Shipbubble live rates, label booking, courier coverage and tracking callbacks/polling.

## Required before accepting real orders
1. Copy `.env.example` to `.env` locally; never upload `.env` or share its values.
2. Set a real PostgreSQL `DATABASE_URL` and a unique random `SESSION_SECRET` of at least 32 characters.
3. Configure and test Paystack and Shipbubble in their test/sandbox environments before enabling live operations.
4. Set up durable production PostgreSQL, automated encrypted off-site backups, and test restoration.
5. Configure the production domain, HTTPS, email delivery, monitoring and alert destination.
6. Load verified products, prices, images, weights, inventory and supplier details; keep sample products disabled.
7. Complete an end-to-end test purchase, cancellation/return, refund and delivery-tracking test before public launch.

**Readiness statement:** the source package passes its included automated tests and syntax checks. It is not certified as production-live until the external checks above have been completed.
